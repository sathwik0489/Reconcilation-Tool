# External integrations release verification

The executable release includes the redesigned navy/teal UI, generic REST/PostgreSQL/ServiceNow adapters, OAuth PKCE/token lifecycle, validated CSV import, table registration/creation, branch mapping, bounded reconciliation and results/export. Earlier foundation-only reports are historical.

Backend suite currently covers 47 tests on real PostgreSQL, including all original authentication/migration tests. Integration tests validate encrypted/redacted credentials, ownership/roles, host/DNS rules, TLS SNI pinning, redirects/retries/response limits, resource/schema behavior, OAuth state/PKCE/code exchange/refresh/scopes, local revocation, signed webhook replay handling, CSV validation/storage, typed coercion, joins/tolerances/aggregation, real ingestion, incremental destination watermarks, real value differences, fan-out unique coverage, and CSV export. Metadata migration rollback and reapplication includes all 25 metadata tables (18 original + seven integration tables) and connector catalog seeds.

The production Next.js build and TypeScript checks pass. Browser verification uses Chromium and emulated iPhone/iPad WebKit; tests cover sign-in/navigation/preferences, PWA offline safety, integration setup review without secret rendering, rejected unauthorized hosts, responsive mapping, and overflow checks. **Final browser suite: 12 passed, no skips, in 53.1 seconds.** Desktop and phone integration/dashboard screenshots were generated for visual QA. Representative pages showed no horizontal overflow.

Testing uses isolated disposable PostgreSQL schemas and generated test accounts. External HTTP responses and connection TLS injection are test fixtures only; no production provider connection or reconciliation result is simulated. No live provider tenant credentials were supplied, so real provider consent/permissions are not yet acceptance-tested. Docker, physical macOS/iPhone/iPad, Edge/Safari, OS PWA installation, load tests, and a full accessibility audit remain unverified here.

One dependency warning remains: installed Starlette TestClient deprecates its httpx transport; tests still pass. Production requests do not use TestClient. The application is suitable for local workflow evaluation with explicitly authorized endpoints; production deployment requires the operational controls and release gates in integrations.md.
